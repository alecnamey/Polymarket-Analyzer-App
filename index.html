How the analysis works

      
The analyzer pulls the top traders from Polymarket's monthly P&L leaderboard, filters them to only the most active traders with the most open positions, then finds markets where multiple of those traders hold positions at the same time.

      
Leaderboard → Activity filter → Position filter → Top N → Overlap analysis


      
Leaderboard Size

      
Range: 1 – 500  |  Default: 100

      
How many traders to pull from the top of the monthly P&L leaderboard before any filtering begins.

      
Larger values cast a wider net and may surface more overlapping markets, but take longer — each trader requires separate API calls for activity and positions. The API returns 50 traders per page, so values above 50 trigger multiple requests automatically.


      
Min Trades / Day

      
Range: 0 – 1000  |  Default: 10

      
Minimum average daily trades a trader must have made over the Activity Window to qualify for the analysis.

      
This filters out traders who appear on the leaderboard from a single lucky position rather than consistent active trading. Setting this to 0 disables the activity filter entirely.


      
Activity Window

      
Range: 1 – 365 days  |  Default: 30

      
How many days back to measure each trader's trading activity.

      
The total trade count over this window is divided by the number of days to produce the trades-per-day figure. Shorter windows capture recent momentum; longer windows reward sustained consistency.


      
Min Active Positions

      
Range: 0 – 1000  |  Default: 30

      
Minimum number of currently open positions a trader must hold to qualify.

      
Traders with very few open positions rarely produce meaningful overlaps. Higher values focus on traders broadly exposed across many markets. Setting this to 0 disables the position-count filter.


      
Traders to Analyze

      
Range: 1 – 200  |  Default: 10

      
How many traders to include in the final overlap analysis, taken from the qualifying pool sorted by monthly P&L (highest first).

      
More traders means more potential overlaps but also more noise. 10–20 is a good starting point. If fewer traders pass the filters than this number, all qualifying traders are used.


      
Overlap filter

      
All positions — shows every market where 2 or more of the selected traders hold any position, regardless of which outcome they chose. This includes markets where traders are on opposing sides.

      
Same outcome — only shows markets where every overlapping trader is on the same side. This is the strongest signal: multiple independent top traders independently arrived at the same directional bet.
